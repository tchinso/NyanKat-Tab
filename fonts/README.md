G마켓 산스와 여기어때 잘난체의 웹폰트는 Reference에서 사용한 Project Noonnu CDN의 파일을 사용합니다. 고운돋움, 주아체, 동글체는 [Google Fonts 저장소](https://github.com/google/fonts)의 원본 TTF입니다. 눈누 기초고딕은 제작자가 안내하는 웹폰트, 나눔스퀘어 라운드는 NAVER 웹폰트이며, 포천 서체는 시청 공식 배포 ZIP의 원본 TTF입니다. 글꼴 파일의 글리프나 내부 이름을 편집하지 않았습니다.

G마켓 산스, 고운돋움, 주아체, 동글체, 나눔스퀘어 라운드는 OFL 조건을 따릅니다. 눈누 기초고딕은 제작자 사용 규정, 여기어때 잘난체는 동봉 사용 가이드, 포천 서체는 원본 형태 유지와 유료 양도·판매 금지 조건을 따릅니다. 자세한 조건은 각 안내 파일을 확인해 주세요.

`NyanKat...` 이름은 페이지에 이미 등록된 글꼴과 충돌하지 않도록 사용하는 CSS / FontFace 별칭입니다. PC에 설치된 글꼴은 복사하거나 배포하지 않습니다.
